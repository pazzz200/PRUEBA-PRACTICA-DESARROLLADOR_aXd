# hotel-reservas

Explicación del proyecto.

## Estructura

- `app.py`: aplicación principal.
- `plantillas/`: páginas HTML de la aplicación.
- `base_datos/`: scripts y datos iniciales de la base de datos.
- `documentacion/`: capturas y diagramas del proyecto.
- `Dockerfile` y `docker-compose.yml`: configuración de contenedores.
- `requirements.txt`: dependencias de Python.
